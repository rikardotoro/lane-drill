# Demo data sources

- **`demo.csv` is synthetic.** Generated by
  [`scripts/make_demo.py`](../../../scripts/make_demo.py) with a fixed seed —
  regenerate it yourself and you get a byte-identical file. Real per-shipment
  ocean transit data is effectively never published under a permissive
  licence, so this repo manufactures a plausible lane and says so, rather
  than dressing up unrelated data. The carrier promise is set at the lane's
  own P80 so the baseline promise-miss rate is honest.
- **`portwatch_{suez,bab_el_mandeb,panama}.csv` are real.**
  Source: IMF PortWatch (https://portwatch.imf.org/), Daily Chokepoint
  Transit Calls, retrieved 2026-08-16 by
  [`scripts/fetch_episodes.py`](../../../scripts/fetch_episodes.py) from the
  public ArcGIS endpoint. The committed slices are a transformation of the
  source data: only `date` and `n_total` per chokepoint, 2019-01-01 to
  2024-12-31. IMF data terms require attribution and a note when data is
  transformed — both given here.
- **Detector constants are measured decisions** (see the docstring in
  `episodes.py`): baseline = 182-day rolling median lagged 30 days;
  episode threshold 0.75; minimum 5 days; gaps under 7 days merge. The
  `panama-drought` alias points at 2023-11 because that is when the slot
  cuts actually crossed the threshold — not the drought's meteorological
  start.
